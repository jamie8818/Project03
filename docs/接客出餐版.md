> 2026-07-07 與 JJ 逐輪對過佈局與機制，全程用 mockup 選定。
> 這是「打工接客」的第三版：把四選一問答改成 **Diner Dash／料理媽媽式的限時拖曳出餐**。
> 動工前的藍圖；數值可在實測後微調。

## 0. 為什麼再改一次

- 打工 1.0＝招呼語四選一（被 JJ 嫌換皮測驗）。
- 打工 2.0（現行 `Games.tsx` 的 `Shift`）＝排隊＋耐心條＋一客多步驟，仍是四選一，且題庫 `serving.ts` 的 `EXCHANGES` 是**跟 SRS 斷開的孤島**（`serveTier` 只看學過幾張、不看學過哪些字）→ 違反「無教不考」。
- 3.0＝出餐動作遊戲。臨場感、爽度都升級；**用 pre-lesson 自帶教考閉環**解掉無教不考，又不必把食物塞進主課綱 SRS（食物字本來就不該佔 N4 考試字的額度）。

## 1. 一句話定位

限時出餐動作遊戲：客人講日文點餐 → 你從道具欄拖對的食物給他 → 快狠準賺小費和 Google 星，星越高客越多、越手忙腳亂。

## 2. 畫面分區（直屏，iPhone 比例）

由上到下：

1. **HUD（放大醒目）**：★ 星評｜⏱ 計時｜¥ 營業額 —— 玩家隨時要瞄的三個數字，各佔一條。
2. **客人區（近半屏）**：客人**從左進場排隊、往右推進**，最前面正在服務的在**右邊出餐口**；當前客人頭上是日文氣泡（可點 TTS）＋耐心條。
3. **攤子檯面線**：視角分隔（老闆往外看的地平線）。
4. **道具欄（加高，2×5 固定格）**：今天 10 種食物全露、拖曳出餐；右上角垃圾桶。

## 3. 核心循環（一場 60 秒）

1. **進場**：pre-lesson 卡片，教/複習今天這 10 種（已熟的可快速滑過）。卡片＝大插圖＋日文＋kana＋中文＋TTS＋例句。
2. **開店**：客人從左陸續進場排隊，同時最多 `SEATS=4` 位在場。
3. **點餐**：當前客人氣泡出日文（＋TTS），耐心條開始倒數。
4. **拖食物 → 判定**：
   - **對** → 客人滿意離場；依「反應速度」給星（越快越多星）＋小費；連對累積 combo 倍率。
   - **錯** → 客人生氣（切成生氣貼圖）、這單 1 星＋扣成本；若食物還沒送出、發現錯了 → 丟垃圾桶（小扣成本、**不**降星）。
5. **口碑滾雪球**：Google 星＝最近 N 位客人的滑動平均 → 決定來客速度（有保底客流打底，不會歸零）。
6. **收工**：時間到、或玩家按「打烊」提早收 → 結算：營業額換金幣、平均星更新單場最佳、常客累積。

## 4. 難度階梯（MVP 先做第一層）

| 階 | 客人怎麼點 | 練什麼 |
|---|---|---|
| **MVP** 指名單品 | 「プリンをください」 | 聽辨單字 |
| v2 數量 | 「プリンを**ふたつ**」拖兩次 | 數字 |
| v2 描述 | 「**あまいもの**」「**つめたい**飲み物」 | 形容詞＋分類（靠 `FoodItem.tags`） |
| 旋鈕 | 進階客人「只播音、字要點才出」 | 純聽力 |

## 5. 預設數值表（實測後可調）

| 項目 | 預設 | 備註 |
|---|---|---|
| 一場時長 | **60 秒** | 可提早打烊 |
| 同時在場客人 `SEATS` | **4** | 慌亂度主旋鈕 |
| 耐心滿值 / 掉速 | 100 ／ 約 6/秒 | 約 16 秒見底 |
| 反應速度→星 | <2.5s＝5★｜<4s＝4★｜<6s＝3★｜<9s＝2★｜其餘/超時＝1★｜給錯＝1★ | 從氣泡出現起算 |
| 小費公式 | `(5 + 星×5) × combo倍率` | 5★滿速≈30／單 |
| combo 倍率 | 連對 3 起 ×1.5、6 起 ×2、失誤歸零 | 沿用現有 combo |
| 給錯客人扣成本 | −15 | 食材＋商譽 |
| 垃圾桶扣成本 | −5 | 純食材浪費 |
| 來客間隔 | `clamp(5.5 − 星×0.6, 1.5, 5.5)` 秒 | 星高客湧入 |
| 保底客流 | 最慢每 5.5 秒必來一位 | 防死亡螺旋 |
| 滑動視窗 N | 最近 10 位 | 星評只看近況 |
| pre-lesson 食物數 / 池子 | 10 ／ 目標 100+ | 場間輪替 |

## 6. 資料結構（TS 草稿，食物庫獨立於主 SRS）

```ts
interface FoodItem {
  id: string; ja: string; kana: string; zh: string;
  price: number;
  category: '飲料' | '甜點' | '正餐';   // 給「描述點餐」用
  tags: ('甜'|'冰'|'熱'|'鹹')[];        // 「あまいもの」靠這比對
  art: string;                          // Codex 生的去背 PNG
}
const FOOD_POOL: FoodItem[];            // 上百種
// 每場：todayFoods = 從池子抽 10（未學優先＋摻幾張生疏）
type FoodMastery = Record<string, number>;  // 存 UserState，跟 cards 分家

// 關卡執行期（單場、不落庫）
interface Shift {
  todayFoods: FoodItem[];
  customers: Customer[];   // {id, sprite, order:FoodItem, mood, patience, enterAt}
  recentStars: number[];   // 最近 N，算滑動平均
  cash: number; combo: number; timeLeft: number;
}
// 結算落 UserState：coins += cash、shiftBest、regulars、foodMastery
```

## 7. 美術（西村風、非像素、去背 PNG）

- **場景 base**：夜市攤位一張背景圖（老闆視角往外看：街景＋攤子檯面前緣）。交 Codex 生。
- **食物插圖**：首批 10–20 種，統一畫框尺寸／打光／去背（プリン・コーヒー・ケーキ…）。交 Codex 生。
- **客人**：西村（Studio U.G.）**10 個角色**，一角色＝一種客人（konezumi/warumeneko/saenaineko/loverabbit/kanedakon/kaeru/kobito/pekio/piko/obakakonezumi；熊貓＝店長排除）。來源＝LINE 商店下載去背（`scripts/fetch-line-product.py`＋`place-customers.py`），入 `public/baito/customers/`。
- **⭐ 每個客人要 5 個動作**（不只 3 表情）——對應接客流程的各狀態：

  | slug | 動作 | 觸發狀態 |
  |---|---|---|
  | `{c}0` | 有精神地走進來 | 進場、排進隊伍 |
  | `{c}1` | 講話（點餐） | 輪到他、氣泡出日文 |
  | `{c}2` | 等待中 | 耐心條倒數、等你上餐 |
  | `{c}3` | 拿到餐點·滿意 | 給對 → 滿意離場 |
  | `{c}4` | 拿錯·生氣 | 給錯 → 翻臉＋降星 |

  可加微動畫：走進來＝從左滑入、等待久了輕微抖動/冒汗。
- **小物**：垃圾桶、星星＋小費飄字特效（可先用簡圖佔位）。
- **店長熊貓**：沿用現有姿勢，pre-lesson 出場帶教學。
