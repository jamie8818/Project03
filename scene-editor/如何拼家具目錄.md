# 家具目錄（catalog.tmx）— 使用說明

在這裡拼出**所有你想讓玩家在店裡「買」的家具**。我會逐件切成 sprite、做成商店品項。

## 打開
雙擊 `catalog.tmx`（跟 cafe.tmx 一樣用 Tiled）。是一張 28×24 的空表，有三個圖層。

## 四個圖層＝家具的 z 層級（很重要，由下往上疊）
**畫每件家具前，先在 Layers 點對它該屬於哪層：**

| 圖層 | 放這類 | 例子 |
|---|---|---|
| **1_rug**（最下） | 地毯／蓆墊（壓在家具底下） | 地毯、榻榻米蓆 |
| **2_furniture** | 站地板的家具 | 桌、椅、櫃、盆栽、架、爐 |
| **3_surface** | 放在家具「上面」的小物 | 盤子、杯子、食物、茶壺、擺飾 |
| **4_wall**（最上） | 貼牆的裝飾 | 掛畫、窗、壁架 |

（遊戲裡由下往上疊：地毯 < 家具 < 桌上物 < 牆飾。surface 物會吸附疊在 furniture 上、渲染其上。）

## 怎麼放
- 一件一件放，**每件之間至少留 1 格空隙**（我才切得開、不會黏成一坨）
- 用對圖層 + 對的筆刷分頁（Room_Builder / Generic / Japanese / Kitchen / Ice_Cream）
- 多格的家具（例如整組桌椅）在筆刷上框選整件再貼

## 命名（可選，但幫助很大）
放完後，如果方便，可以在對話裡跟我說「左上是茶桌、右邊那排是杯盤…」，或直接讓我切好再一起命名/定價。

## 完成
Cmd+S 存檔 → 跟我說「目錄好了」→ 我切 sprite、接進商店 catalog。

不用一次做完，先放幾件也行，之後隨時加。
