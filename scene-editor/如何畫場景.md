# 咖啡廳場景編輯器 — 使用說明

用滑鼠畫你的店面，畫完存檔跟我說，我接進 app。全程不用寫程式。

## 一、裝軟體（只做一次）
1. 到 **https://www.mapeditor.org** → 點 Download → 下載 **Tiled**（Mac 版，免費）
2. 安裝、打開

## 二、打開專案
- 雙擊這個資料夾裡的 **`cafe.tmx`**（或在 Tiled 裡 File → Open 選它）
- 會看到一個 **24×16 的空房間**，右邊有 5 個素材筆刷

## 三、怎麼畫（重點：由下往上，一層一層畫）
左邊 **Layers（圖層）** 面板有三層，**畫之前先點對要畫的那一層**：

| 順序 | 圖層 | 用哪個筆刷 |
|---|---|---|
| 1 | **1_Floor**（地板）| `Room_Builder` 分頁裡的地板磚 → 鋪滿整個房間 |
| 2 | **2_Walls**（牆）| `Room_Builder` 裡的牆 → 畫上面幾排 |
| 3 | **3_Furniture**（家具）| `Generic`／`Japanese`／`Kitchen`／`Ice_Cream` → 把櫃檯、榻榻米、桌椅、盆栽擺上去 |

**畫法**：右邊 tileset 點一個 tile（或用滑鼠**框選一整件多格家具**，例如整個櫃檯）→ 游標變筆刷 → 到畫布上點一下 / 拖曳貼上。

## 四、幾個小提醒
- **一定先在 Layers 點對圖層再畫**，不然會畫到錯的層
- 家具常是「多格」的：在素材上框選整件再貼，別一格一格貼
- **不用管熊貓店長和客人**——那些我用程式加，你只要畫「空房間＋家具」
- 想要靈感：打開 `assets_src/limezu/6_Home_Designs/Japanese_Interiors_Home_Designs/32x32/Japanese_Home_1_preview_32x32.png` 看官方怎麼擺日式房

## 五、畫完
1. **Cmd + S** 存檔
2. 跟我說「**場景畫好了**」
3. 我把 `cafe.tmx` 接進 app 的 Shop 場景

畫壞了不要緊，隨時可以重畫、或叫我幫忙。
